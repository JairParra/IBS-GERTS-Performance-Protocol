# IBS & Acid Reflux Performance Protocol

This project is a static web application presenting an 8-Week IBS and Acid Reflux Clinical Dietary Protocol. It organizes clinical dietary guidance, behavioral directives, macro targets, and interchangeable meal rotations into a responsive single-page experience designed for clear reading on desktop and mobile.

## Project Overview

The site is intended to display a structured healing-phase nutrition protocol with:

- core mechanical and nutritional directives
- ingredient-specific guidance and restrictions
- macro and portioning recommendations
- three interchangeable weekly menu rotations across an 8-week protocol

## Tech Stack

- HTML5 for semantic page structure
- CSS3 for presentation, responsive layout, and visual design
- Vanilla JavaScript for progressive enhancement and interactive schedule rendering

## Local Development

This is a static site with no build step or package installation required.

### Run locally

1. Clone or download the repository.
2. Open the project folder in your editor.
3. Open [index.html](index.html) in a browser.
